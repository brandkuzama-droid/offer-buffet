# عرض سعر - بوفيه سحور / فطور

صفحة ويب لإنشاء عرض سعر لبوفيه السحور والفطور، مبنية على نموذج شركة الخزامى التجارية.

## المميزات
- حساب تلقائي للسعر حسب: عدد الأشخاص × عدد الأيام × سعر الشخص لكل بوفيه (سحور / فطور)
- خصم اختياري (بدون / 10% / 15% / 20% / 25%)
- ضريبة قيمة مضافة قابلة للتعديل (افتراضي 15%)
- أسعار الشخص الواحد لكل بوفيه قابلة للتعديل من قسم "إعدادات الأسعار" أسفل الصفحة، وتُحفظ تلقائيًا في المتصفح
- زر طباعة / حفظ PDF
- زر تصفير للبدء من جديد

## التشغيل
افتح ملف `index.html` مباشرة في المتصفح، أو انشره على أي استضافة استاتيك (مثل Netlify أو GitHub Pages).

## ملاحظة
شعار الشركة (`logo.png`) غير مرفق تلقائيًا — أضف ملف الشعار بنفس الاسم `logo.png` في نفس المجلد ليظهر في أعلى الصفحة.
